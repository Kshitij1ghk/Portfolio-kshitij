01 — About

How I work

I build full-stack software, and I like the parts that are unglamorous: the schema, the business rules, the edge cases. Most of my repositories are C#/.NET applications — a restaurant POS, a library management system, a personal expense tracker — sitting on SQL databases I designed, alongside a web layer built with JavaScript, HTML and CSS.

Lately I've been pushing the same discipline into applied AI. Most of that work sits at the seam between a retrieval system and a language model — the place where things quietly go wrong: a hallucinated answer, a prompt injection smuggled through a retrieved document, a model confidently answering a question nobody in the corpus ever documented. So I treat those as engineering problems, not model problems. The RAG assistant refuses deterministically when nothing relevant clears the similarity floor instead of paying an LLM call to hallucinate. The MCP assistant sandboxes every write behind an explicit approval gate.

I'm part of the StudyGrillTogether organization, where we collaborate on learning projects and share knowledge across programming domains. Outside of that, I'm technical coordinator for my department's student association, running technical events and code sessions for the cohort.

RAG

Business RAG Assistant

Python · FastAPI · Qdrant · FastEmbed · Gemini

End-to-end retrieval-augmented QA over internal policy documents: chunking, 384-dim BAAI/bge-small embeddings via local ONNX inference (no external embedding API, so no per-query cost), Qdrant storage with HNSW and cosine similarity, then grounded answer synthesis with source citations, similarity scores and confidence bars in the UI.

Engineering notes
  • A 0.40 similarity floor returns a deterministic refusal without calling the LLM when nothing relevant is retrieved — a hallucination is not an acceptable answer to "I don't know".
  • Retrieved chunks are passed as untrusted data, not instructions, to resist prompt injection carried inside the corpus.
  • 16 passing pytest tests, plus a diagnostic retrieval script for tuning the threshold empirically.
  • RAG
  • ONNX
  • HNSW
  • Citations
  • pytest
MCP

MCP-Powered Developer Assistant

Python · MCP · GitHub API · AST · pytest

An MCP client/orchestrator wiring separate code, GitHub and test MCP servers into multi-step agent workflows — locate a bug, inspect symbols, triage the matching issue, generate a patch, validate it — with interactive [Y/N] approval gates before any change is written.

Engineering notes
  • Codebase access via Python AST parsing — classes, functions, arguments, docstrings and line ranges — confined to an ALLOWED_DIR jail with path-traversal prevention.
  • Diff-based patch generation and sandboxed pytest execution with timeouts.
  • 16 unit and integration tests spanning the code, patching, GitHub and agent-flow layers.
  • MCP
  • AST
  • Agent workflows
  • Sandboxing
  • GitHub API
